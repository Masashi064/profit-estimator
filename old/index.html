評価損益率・利益・売却額 相互計算ツール

3つのうち2つを入力すると残り1つを自動計算します。
・評価損益率は百分率（%）で入力（例：184、-35.2）
・利益・売却額は金額。負の値（損失）にも対応。
・単位は「円 / 万円」を固定表示で切り替え可、丸め方も指定できます。

利益 合計: 0 売却額 合計: 0 単位: 円（¥）
評価損益率 （%） 利益 （円） 売却額 （円） メモ 操作

数式（rは百分率）：
・売却額 = 利益 × (1 + 100 / r)
・利益 = 売却額 / (1 + 100 / r)
・評価損益率(%) = 100 × 利益 / (売却額 − 利益)（売却額＝利益のとき不可）
